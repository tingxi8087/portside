# Portside 界面与交互设计

更新日期：2026-10-15

状态：设计方向已确认，已实现首轮静态预览，供界面与操作路径验收。当前范围与验证边界见 [静态预览说明](./静态预览说明.md)。

关联文档：[产品规划](./产品规划.md)。本文细化界面与交互，不代表功能已实现。尺寸和视觉参数为初始设计基准，允许通过实际界面验证调整。

## 1. 设计目标

以 macOS 活动监视器式工具窗口为参考：简单、紧凑、直接操作。

2026-10-15 用户验收修订：上一版侧栏工作台过于复杂，改为顶部四个 Tab。以下布局要求优先于上一版截图和描述。

- 顶部只有端口、进程、终端、SSH 四个功能 Tab。
- 移除侧栏、大标题、宣传性说明、独立概览、底部装饰和重复演示提示。
- 工作区直接显示一行操作工具栏与内容。
- 演示状态只在窗口右上角保留小型标记。
- 保留原有搜索、排序、详情与演示操作能力。

## 2. 窗口与布局

- 默认窗口约 960 × 640，最小 760 × 480。
- 顶部约 52px：左侧原生窗口按钮与小型应用名称，中间四个分段 Tab，右侧演示标记、快速操作与设置。
- 页面工具栏约 43px：常用操作、筛选、数量与右侧搜索。
- 列表紧接工具栏，从窗口左侧铺满内容区；表格行高约 31px，单行显示。
- 名称与辅助信息并排，图标为小型单色图标；表格使用细分隔和轻微交替行底色。
- 端口与进程页固定为左侧列表、右侧进程详情布局；未选中时右侧显示空状态，不覆盖列表。
- 设置作为工具栏弹窗，不占用第五个功能 Tab。
- 终端左侧为会话，右侧固定展示快捷指令；标题栏加号用于新增，不再提供展开和收起。
- SSH 左侧为远程会话，右侧固定为连接 / 文件两个 Tab；文件跟随当前会话切换。
- 支持 Tab 键、左右方向键、Home/End 切换顶部功能 Tab。
- 首次打开进入端口，后续记住上次功能页面；当前应用运行期间切换页面保留会话。

## 3. 端口页

### 页面组成

- 一行工具栏提供刷新图标、端口范围下拉、数量和即时搜索。
- 主表格默认展示端口、进程、PID、监听地址、操作。
- 协议使用轻量文字标记，其他信息进入详情。
- 点击行或进程名，在固定右侧面板查看完整命令与关联端口；未选中时显示空状态。
- 详情中的“查看进程”跳转到进程页并定位该对象。

### 搜索与结束流程

1. 输入端口、进程名或 PID 后立即筛选，无须点击搜索。
2. 每行提供“结束”文字按钮。
3. 点击后按钮原位显示“正在结束”。
4. 确认进程退出且端口释放后，短暂显示“已释放”，随后移除该行。
5. 若仍有其他进程占用该端口，应刷新展示实际占用情况，不错误宣告释放。
6. 失败时保留行和具体原因，并提供下一步操作。
7. 正常退出请求未生效时，就地提供“强制结束”。

### 操作约束

- 自己的普通进程默认不弹确认框。
- 系统进程、其他用户进程和强制结束需要更明确的目标提示与必要确认。
- 结束的是进程，其其他端口也可能关闭，界面文案必须明确。
- 结束按钮默认保持克制，悬停或键盘聚焦时突出危险色。
- 执行前由后端重新核对进程身份，避免 PID 复用导致误操作。
- 权限不足或操作失败必须真实反馈。

## 4. 进程页

- 默认列为名称、CPU、内存、PID。
- 磁盘、网络等通过工具栏列设置图标开启，记住用户选择。
- 点击列标题切换升序、降序，并显示排序方向。
- 搜索支持名称和 PID，提供“我的进程 / 全部进程”下拉筛选。
- 单击行选中并高亮，在固定右侧面板展示详情；取消选择后面板保留并显示空状态。
- 结束操作放在选中后的工具栏及详情中，减少表格误点。
- 数值使用固定精度与稳定宽度，更新时整行不闪烁。
- 不可采集的指标展示不可用及原因，不以 0 代替。

### 实时更新与稳定性

- 用户正在悬停、选择或操作某一行时，暂缓排序导致的位置变化。
- 期间继续更新数据，操作结束后再调整顺序。
- 选中状态绑定进程身份，不绑定行号。
- 提供暂停刷新按钮，方便比较和观察。

## 5. 本地终端与快捷指令

### 终端工作区

- 顶部为会话标签和新建按钮，其余空间交给终端。
- 支持真实交互、复制粘贴、清屏、搜索输出、新建、重命名和关闭。
- 标签以小状态点表达运行状态，同时提供可理解的文字状态说明。
- 切换应用页面后保留会话。
- 关闭仍有任务运行的标签时确认，已退出的会话直接关闭。
- 本地会话明确标注本地目标，避免与远程会话混淆。

### 快捷指令面板

- 快捷指令固定显示在终端右侧，标题栏加号新增，不提供关闭按钮。
- 列表默认显示指令名称和执行目录。
- 点击指令后，在指定目录的新终端标签中执行。
- 支持收藏，常用指令排在前面。
- 运行、收藏、编辑、复制、删除作为行内图标直接展示，悬停或键盘聚焦显示功能说明。

### 新增与编辑

小弹窗只展示三个必填项：名称、工作目录、命令。

- 工作目录提供文件夹选择按钮，新增时默认使用上次选择的目录。
- 命令支持多行输入。
- 底部提供“保存”和“保存并运行”。
- 执行输出可见，任务可停止。
- 高级环境变量、分组、执行前确认和远程执行按产品规划后续扩展。

## 6. SSH 连接

### 未连接视图

- 使用紧凑服务器列表，不使用大卡片。
- 每条显示连接名称、用户名@主机:端口、状态和连接按钮。
- 每行直接展示连接、编辑、删除三个图标，不再收入更多菜单；悬停或键盘聚焦显示功能说明。

### 新增服务器

- 新增与编辑共用紧凑弹窗：名称和用户名并排，主机和端口并排，认证方式横向排列。默认宽 480px、实测高约 334px，密码与密钥模式保持一致。
- 字段使用小尺寸组件与局部紧凑间距，不改变其他弹窗；效果见 [SSH 连接弹窗](screenshots/ssh-compact-form.jpg)。
- 首先展示名称、主机、用户名和认证方式。
- 端口默认 22，直接显示在主机旁。
- 根据密码或私钥认证切换对应字段，避免一次展示完整大表单。
- 凭据存储、主机指纹和权限遵循产品规划中的约束。

### 连接后视图

- 在 SSH 工作区打开会话标签，支持多个服务器并行使用。
- 标签优先显示用户设置的连接名称，始终能够确认远程目标。
- 明确区分正在连接、等待认证、已连接、已断开和失败状态。
- 失败原因显示在会话内，旁边提供“重试”和“编辑连接”。
- 左侧始终是远程终端区，未连接时显示空状态；右侧固定展示连接 / 文件 Tab。

## 7. 远程文件面板

- 在固定右侧面板切换到“文件”Tab，左侧终端始终可见；当前服务器名称明确显示。
- 顶部展示可编辑的当前路径、返回上级、刷新、上传。
- 文件列表展示名称、大小、修改时间。
- 双击文件夹进入，选中文件后可下载。
- 拖入本地文件上传。
- 右键菜单提供重命名、删除、复制路径；同时提供可发现的菜单入口，避免功能只能通过右键使用。
- 更多菜单提供“在此目录打开终端”。
- 传输进度放在面板底部，可收起、可取消，失败原因可查看。
- 普通传输不反复弹窗；删除与覆盖时明确显示目标文件及必要确认。

## 8. 视觉规范

整体方向为接近 macOS 活动监视器的紧凑工具窗口，采用 Paper Ink 纸墨风格。暖白纸色、墨黑文字和灰色选中态，不再使用绿色强调。

| 项目 | 初始设计方向 |
| --- | --- |
| 浅色主题 | 白色工作区、浅灰工具栏、深灰文字 |
| 深色主题 | 石墨底色，面板以少量明度差区分 |
| 强调色 | 墨黑（浅色主题）或浅纸色（深色主题），用于焦点和主要操作 |
| 危险色 | 红色，专用于危险操作和失败 |
| 图标 | 统一细线风格，约 14–16px |
| 正文 | 约 13px，清晰易读的界面字体 |
| 数据与路径 | 等宽字体，用于端口、PID、路径及资源数值 |
| 表格 | 行高约 31px，单行展示名称与辅助信息 |
| 分隔与层次 | 轻分隔线、少阴影、克制圆角 |
| 动效 | 短暂、轻微的状态反馈，实时列表无入场动画 |

列表为主，少用卡片、重复边框与大标题。

### 背景与主题设置

- 支持浅色、深色、跟随系统。
- 背景图片默认关闭，开启后主要体现在窗口底层与工具栏。
- 表格、表单和终端保持稳定的阅读底色。
- 支持透明度、模糊、遮罩调整，直接预览并可恢复默认。
- 终端配色可以独立选择或跟随应用主题。

## 9. 全局交互规则

- 搜索即时生效，不增加提交步骤。
- Esc 按上下文关闭最上层面板或清空搜索；终端聚焦时保留终端所需按键行为，避免全局快捷键抢占输入。
- 页面新建操作保留文字；列表行内操作统一使用图标与 Tooltip，不隐藏在更多菜单中。
- 常用动作提供文字，图标按钮提供悬停说明和可访问名称。
- 加载和操作状态原位展示；成功提示短暂出现，失败信息保留至处理或关闭。
- 空状态说明当前情况并提供一个明确动作。
- 支持键盘导航与清楚可见的焦点。
- Cmd+K 打开快速入口，支持查找端口、切换会话、连接服务器、运行已保存指令。
- 所有快捷功能都有完整鼠标入口。
- 本地和远程会话始终明确标注操作目标。

## 10. 界面验收重点

- 高频任务无需经过仪表盘、冗长表单或多层菜单。
- 搜索、结束、连接、执行、上传下载均有明确状态和结果。
- 实时刷新不打断正在进行的行选择与操作。
- 多个会话与服务器之间切换不丢失上下文。
- 浅色、深色及自定义背景下，表格与终端均清晰可读。
- 小窗口下主要操作可用，次要信息能够按需查看。
- 危险操作目标明确，失败不被误报为成功。
- 以实际桌面界面和真实操作闭环验证，不只依据源码或构建成功。

## 11. 组件与纸墨主题修订（2026-10-15）

按用户验收反馈，所有界面按钮与选择控件统一使用 Paper Ink，保留原有紧凑布局。

- 顶部功能导航使用 Tabs。
- 工具栏、窗口入口、终端标签操作、快捷指令、文件操作统一使用 Button。
- 搜索和文件路径使用 Input；筛选使用 Select。
- 行内操作使用 Button + Tooltip 直接展示；认证、主题和终端配色使用 Segmented。
- SSH 端口使用 InputNumber，透明度和模糊使用 Slider，传输进度使用 Progress。
- 应用色板统一为纸白、墨黑和中性灰，终端输出、状态、提示、选中态和应用图标一并去绿。
- 设置中移除彩色强调色选项；保留浅色、深色、跟随系统、自定义背景和终端明暗配色。
- 已保存的连接与快捷指令继续保留，旧版强调色配置在读取时忽略。
- 原生窗口交通灯保持系统配色；危险和错误沿用必要的语义提示。

最新效果见 [纸墨版端口页](screenshots/paper-ink-ports.jpg) 和 [纸墨版设置](screenshots/paper-ink-settings.jpg)。

## 13. 固定进程详情面板（2026-10-15）

端口与进程页共用固定左右分栏布局，右侧约 300px；窄窗口约 260px。列表与详情各自滚动，额外指标导致列表过宽时仅在列表区横向滚动，不覆盖右侧。

初始未选中、取消选择、选中进程被结束时，面板显示“未选择进程”空状态。右上角叉号用于取消选择，不关闭面板。端口页支持点击整行选择进程，结束图标不会触发行选择。

已实际验证空状态、选中详情、取消选择、结束后空状态，以及 760 × 480 窗口下不重叠且列表可横向滚动。

## 14. 终端与 SSH 固定右栏（2026-10-15）

按用户确认的方案实现静态预览：

- 终端：左侧终端标签与输出，右侧固定快捷指令列表；标题栏加号新增，空列表提供添加入口。移除快捷指令开关与面板关闭按钮。
- SSH：左侧远程终端，右侧固定连接 / 文件两个小 Tab，默认连接。连接区含搜索、新增与每条连接的三个操作图标。
- 未连接时左侧提示选择右侧连接，文件区显示未连接空状态。
- 点击连接在左侧创建演示会话，右侧保留连接列表；切换到文件后，内容跟随当前终端所属服务器。
- 文件区显示服务器名称，目录与演示文件变更按服务器缓存在内存中，切换服务器或主页面仍保留；刷新与重启后重置。
- 文件面板和终端之间始终有固定分隔，不再以抽屉覆盖。所有右侧栏统一约 300px，小窗口约 260px。
- 模拟传输进度仍位于文件面板底部；切换右侧 Tab 或会话不会重新初始化已经挂载的文件面板。

## 15. SSH 新增入口与测试连接（2026-10-15）

- 移除 SSH 终端标签栏加号，统一使用右侧连接区的新增入口；本地终端仍保留新建标签。
- 新建与编辑连接弹窗底部左侧增加「测试连接」，右侧保留取消、保存连接，沿用紧凑布局。
- 测试使用当前未保存的主机、用户名、端口配置，先校验输入，再展示测试中与模拟结果；不要求填写连接名称。
- 当前仅演示测试流程，结果明确显示「模拟测试通过 · 未发起真实连接」，不读取密钥、不保存密码、不实际连接服务器。
- 修改字段、关闭或重新打开弹窗会清除测试结果，并使尚未完成的模拟测试失效；测试不会自动保存配置或创建会话。

已验证新建与编辑两种入口、测试中与模拟结果、无效主机校验、修改后结果清除，以及 SSH 标签栏无加号、本地终端仍可新增。

## 16. 快捷指令标签与两种复制（2026-10-15）

- 去掉收藏与收藏排序，按原有顺序展示指令。
- 右栏顶部提供搜索与单选标签筛选：全部、自定义标签、未分类。搜索匹配名称、命令、路径和标签，可与筛选叠加。
- 标签横向滚动，右侧固定「管理标签」图标；指令内标签也可以点击筛选。结果数显示为匹配数 / 总数。
- 每条指令的名称行保留运行、编辑、创建副本、删除四个图标；名称也可点击编辑。命令行旁独立提供剪贴板图标「复制命令」，只复制命令文本，不执行。
- 创建副本打开预填表单，带入目录、命令、标签和「原名称 副本」，保存后才新增；取消不会生成数据。
- 新增时继承当前筛选标签。表单支持多选、回车创建新标签，保存时生效；取消不产生标签。

## 39. 快捷指令执行入口与可选目录（2026-10-16）

## 40. CPU 计算与统计口径（2026-10-16）

修复进程 CPU 在 Apple Silicon 上缺少 Mach timebase 换算的问题。CPU 表头悬停说明单核满载为 100%、多核可超过 100%；悬浮球设置、菜单与悬停名称改为「整机 CPU 使用率」，短标签仍为 CPU。进程数值与整机数值采用各自正确的统计口径，不强行使两者相等。复现与回归测试见 [系统能力自测](系统能力自测.md)。


### 进程 CPU 统一为整机口径

进程 CPU 在 Mach timebase 换算后除以在线逻辑核心数，显示该进程占整机 CPU 的比例。例如 10 核机器占满一核显示约 10%，占满全部核心显示约 100%。表头悬停、详情说明与后端提示同步调整；悬浮球采集不变。两处采样时刻、用户筛选和可访问进程不同，列表相加不保证等于悬浮球当前值。

## 43. 进程内存对齐活动监视器

进程内存改用 macOS `proc_pid_rusage` 的 `ri_phys_footprint`，不再使用 `ps` RSS。后端统一输出十进制 MB，前端小于 1000 MB 显示一位小数 MB，大于等于 1000 MB 显示两位小数 GB；排序继续按原始数值，不按显示文本排序。进程列表、进程详情与端口详情共用格式化函数。读取失败显示 `—`，不回退到 RSS；合法零值仍显示 `0.0 MB`。表头悬停与详情说明采用 Footprint 名称。

浏览器示例验收中，同一进程在列表、进程详情和端口详情均显示 `1.49 GB`；MB 行正常显示。README 的公开示例截图与文字同步更新。与活动监视器采用相同内存口径，独立刷新时刻仍可能产生少量读数差异。
