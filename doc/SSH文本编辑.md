# SSH 文件单击打开与文本编辑

2026-10-15

## 交互

- 单击目录进入，单击文件打开独立编辑弹窗，终端布局保持原样。
- 每行独立「⋯」菜单提供下载、重命名和删除，不需要先选中再到列表底部操作。
- 弹窗标题显示文件名和未保存圆点，工具栏显示服务器、完整路径及重新读取、下载、保存图标。
- CodeMirror 提供行号、基础语法高亮、缩进、撤销重做、⌘F 搜索替换、⌘S 保存。保存完成后恢复编辑焦点。
- 关闭及重新读取未保存文件时，提示「保存 / 不保存 / 取消」。保存失败保留内容及错误提示，不自动关闭。
- 主动断开服务器时也检查未保存编辑。独立弹窗打开时遮挡底层终端和连接列表，避免误触。
- 编辑草稿只在当前应用内存中保留，不写入本机配置；真正退出应用不持久化草稿。

## 文本边界与保存

- 支持 1 MB 以内的 UTF-8 普通文件，保留 UTF-8 BOM、LF / CRLF / CR 换行。
- 二进制、非 UTF-8、混合换行或超限文件提供说明和下载入口，不转换后覆盖原文件。
- 通过 SFTP 读取真实内容；符号链接首次读取解析为目标真实路径，同一个服务器同一真实路径复用文档。
- 保存前按内容 SHA-256、修改时间、权限与所有者校验版本，检测同大小、同秒内的内容变化。
- 检查原文件写权限，再写同目录独占临时文件，保留原 uid / gid 和权限，替换前再次检查远程版本。
- 使用服务器声明的 `posix-rename@openssh.com` 扩展替换文件。ssh2 的普通重命名接口不能在 OpenSSH 上覆盖，因此使用独立 SFTP 通道发送该扩展请求，不执行远程 shell 命令。
- 不支持该扩展或写入失败时不主动移除原文件，清理临时文件并保留本地编辑。
- SFTP 无跨客户端的版本比较与替换事务；两次校验可发现通常的并发修改，但最后校验到替换之间仍有很小的竞争窗口。
- 保存保留 Unix 所有者与权限，未复制 ACL、扩展属性等附加元数据。

## 验证

- `cargo test --manifest-path src-tauri/Cargo.toml --lib`：31 项通过，6 项依赖隔离 SSH 的测试默认忽略。
- 单独启用本次隔离 SSH 测试：文本校验、同大小版本变化、真实 SFTP 读取保存、旧版本拦截、权限 0640 保留、只读文件拒绝保存、符号链接解析与替换保护、二进制提示、超限拒绝、临时文件清理均通过。
- 独立协议字段解析测试验证长度截断与非法长度处理。
- 原生 App 使用仅监听本机的临时 SSH 容器验收；不操作用户原有服务器。

原生验收：单击目录、单击打开独立弹窗、CodeMirror 编辑和 ⌘S 实际写回（保留 0640 权限）、⌘F 搜索、远端外部修改拦截并保留本地草稿、关闭取消与保存后关闭、重新读取前修改保护、二进制文件信息均已验证。保存成功后刷新右侧文件列表元数据。

最终弹窗版另验证：中文搜索替换、保存后编辑焦点保留、右侧文件大小从 76 B 自动刷新为 65 B、关闭弹窗后仍为原 SSH 会话。临时服务器和配置均已清理，用户 workspace 配置的规范化 SHA-256 与验收前一致。
