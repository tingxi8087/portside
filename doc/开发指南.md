# 开发与打包

```sh
npm install
npm run dev
```

需要 Rust、Xcode Command Line Tools。Vite 使用 `127.0.0.1:1420`，不要重复启动开发服务器。

```sh
npm run build
```

`dev` 启动 Tauri 桌面应用及其前端开发服务；`build` 构建生产版桌面应用，打包后自动将 `Portside.app` 和对应版本的 DMG 复制到项目根目录 `build/<版本号>/`（已加入 Git 忽略）。Tauri 原始构建缓存仍保留在 `src-tauri/target/`。如需仅启动或构建前端，使用 `npm run dev:web` / `npm run build:web`。

版本号统一修改 `package.json` 的 `version`；应用显示版本、Tauri 安装包版本和产物目录均从中读取，开发及打包前自动同步 Cargo 包版本。

同时启用悬浮球与开机自动启动后，登录启动时只显示悬浮球，主窗口保持隐藏。

设置中的「开机自动启动」默认关闭，勾选后写入 macOS 登录启动项，取消后移除；打开设置时读取系统实际状态，恢复默认外观不会改变启动项。

其他检查与调试打包：

```sh
cargo test --manifest-path src-tauri/Cargo.toml
node scripts/verify-config-storage.mjs
node scripts/verify-system-snapshot.mjs
# 可选：需要 Docker；创建隔离 Linux fixtures 并在完成后清理
node scripts/ssh-fixture.mjs test
npm run tauri -- build --debug --bundles app
```

调试应用位于 `src-tauri/target/debug/bundle/macos/Portside.app`。当前发布流程未配置 Apple Developer ID 签名与公证。SSH 的 OpenSSL 随构建静态编译，无需目标机器安装 Homebrew OpenSSL。


## 技术栈

Tauri 2、Rust、React、TypeScript、Vite、Paper Ink、Zustand 和 xterm.js。项目使用 Hash Router，源码路径别名为 `@/`。
