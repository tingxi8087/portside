# Portside 产品规划

更新日期：2026-10-15

状态：真实系统、PTY、SSH/SFTP 已接入，本机主要流程验收通过。当前证据与限制见 [真实功能验收](./真实功能验收.md)。静态预览说明保留为历史记录。

界面与交互细则见 [界面与交互设计](./界面与交互设计.md)。

## 1. 产品定位

面向 Mac 开发者的轻量桌面工具，将端口、进程、本地终端和远程服务器集中到一个干净的工作空间。

核心体验：快速找到、直接操作、马上看到结果。

- 使用 Tauri 构建 macOS 桌面应用。
- 本地优先、单窗口、少配置。
- 操作简单，界面干净极简，常用操作有直接入口。
- 首版完整覆盖端口、进程、终端、SSH 和外观配置，按阶段交付。

## 2. 导航与页面结构

顶部依次提供终端、SSH、端口、进程四个 Tab，参考 macOS 活动监视器，采用一行工具栏和紧凑内容区；设置从右上角弹窗打开。

| 入口 | 内容 | 高频操作 |
| --- | --- | --- |
| 端口 | 占用端口、对应进程、监听地址、协议 | 搜索端口、结束进程、查看进程 |
| 进程 | 运行中的进程和资源占用 | 搜索、排序、结束、查看详情 |
| 终端 | 本地终端会话、快捷指令 | 新建终端、切换会话、执行指令 |
| SSH | 已保存服务器、远程终端、文件管理 | 连接服务器、传输文件、执行命令 |
| 设置 | 外观、背景、终端偏好、通用配置 | 切换主题、调整背景 |

默认进入终端页。首版不增加独立概览仪表盘。

## 3. 功能范围

### 3.1 端口管理

- 默认展示 TCP 监听端口和 UDP 绑定端口，可切换查看其他连接。
- 显示端口、进程名、PID、协议、监听地址。
- 支持按端口号、进程名、PID 搜索。
- 每行直接提供结束操作，完成后自动刷新并展示结果。
- 点击进程名可跳转到对应进程详情。
- 明确表达结束对象是进程：同一进程的其他端口也可能同时关闭。
- 普通用户进程点击后先请求正常退出；仍未退出时提供强制结束。
- 权限不足时说明原因，不将失败表现为成功。
- 执行前重新核对进程身份，防止 PID 复用导致误操作。

### 3.2 进程管理

- 使用固定左右分栏：左侧列表，右侧进程详情；未选中时显示空状态。
- 基础列：名称、PID、CPU、内存。
- 可选列：磁盘读写速率、网络上传和下载速率、用户。
- 支持表头升序、降序排序。
- 支持名称、PID 搜索，以及我的进程、全部进程筛选。
- 详情展示可获取的命令行、程序路径、启动时间、父进程和关联端口。
- 自动刷新并支持暂停；刷新时保持选中对象和滚动位置稳定。
- 明确 CPU、内存、磁盘和网络指标的统计口径与单位。
- 整机网络流量与单进程网络流量分别处理，后者需要独立验证采集方案。
- 无权限或无法采集的数据显示不可用及原因，不使用 0 代替。

### 3.3 本地终端

- 提供真实可交互终端，支持 vim、top、开发服务等程序。
- 支持多个标签页、新建、重命名、关闭、复制粘贴、清屏和搜索输出。
- 默认使用用户配置的 Shell。
- 切换应用页面保留终端会话。
- 关闭会话时正确清理资源，并明确运行中任务的关闭行为。
- 处理窗口尺寸变化、输入输出、退出状态和大量输出时的流量控制。

### 3.4 快捷指令

固定显示在终端右侧，不独立占用导航入口。

必填字段：

| 字段 | 示例 |
| --- | --- |
| 名称 | 启动前端 |
| 执行目录 | /Users/tingxi/appCode/Portside |
| 命令 | pnpm dev |

- 支持创建、编辑、删除和执行快捷指令。
- 执行时在指定目录创建新的终端标签页，命令输出可见，任务可以停止。
- 配置在应用重启后保留。
- 环境变量、分组、执行前确认和远程执行作为后续扩展。

### 3.5 SSH 连接

- 保存连接名称、主机、端口、用户名和认证方式。
- 支持密码、私钥认证，考虑 SSH Agent 集成。
- 密码与私钥口令按用户确认改为本机明文文件保存（0600 权限），与普通连接配置分开；可选择不保存。
- 首次连接展示主机指纹，保存已信任主机；指纹变化时明确提醒。
- 支持多个服务器同时连接。
- 展示连接中、已连接、断开和失败等状态，失败原因可理解。
- 左侧固定远程终端区，右侧固定连接 / 文件 / 快捷指令三个 Tab，默认显示连接列表。
- 断开后保留服务器配置，明确显示会话状态。

### 3.6 远程文件管理

通过 SFTP 提供基础可视化文件操作：

- 浏览目录、返回上级、输入路径。
- 上传、下载、新建目录、重命名、删除。
- 显示传输进度和失败原因，支持取消。
- 在当前文件目录打开远程终端。
- 对覆盖、删除等操作提供清晰的目标信息与必要确认。

在线编辑器、目录同步和跳板机等不进入首版范围，可后续扩展。

### 3.7 主题与背景

- 提供浅色、深色、跟随系统模式。
- 支持纯色背景和自定义背景图片。
- 支持背景透明度、模糊和遮罩调整。
- 列表与终端保持足够底色和文字对比度。
- 终端配色可以独立选择或跟随应用主题。
- 外观配置在应用重启后保留。

## 4. 视觉与交互方向

采用克制、精密的桌面工具风格。

- 顶部四个 Tab、一行紧凑工具栏、全宽内容区。
- 列表为主，少用卡片，减少重复边框和大标题。
- 使用中性的白色或深灰底色，使用墨黑或浅纸色作为主操作色，不再使用彩色强调。
- 端口、PID 和资源数值使用等宽字体，便于纵向比较。
- 常用操作直接可见，低频操作收入更多菜单。
- 状态变化使用短暂、轻微反馈，持续刷新的列表不做入场动画。
- 搜索、加载、空数据、权限不足和操作失败都有清晰状态。
- 自定义背景不影响表格、表单和终端的可读性。

## 5. 技术方案与责任边界

### 前端

- React 18+、TypeScript、Vite。
- React Router，默认 Hash Router。
- Zustand 管理应用设置、布局等共享状态，页面临时状态留在页面内。
- Less 和 CSS Modules，配置 @/* 指向 src/*。
- 通用控件优先使用 Paper Ink，图标使用 paper-ink/icons。
- 终端展示使用 xterm.js，后端连接真实 PTY。
- 系统能力通过统一的类型化服务层调用 Rust，不在页面中散落底层调用。
- 需要 HTTP 能力时再按约定建立集中请求层，不为本地 IPC 强行增加 HTTP 服务。

### Tauri / Rust

- 系统指标采集、端口与进程映射、进程操作。
- PTY 终端会话及其生命周期。
- SSH、SFTP、主机指纹验证与连接状态。
- 配置持久化、凭据访问、后台任务和资源清理。
- 通过类型化命令和事件与前端通信；校验操作参数及目标身份。

### macOS 适配

- 系统权限及不同进程的可访问范围。
- 进程指标与平台相关采集能力。
- 本地凭据文件与桌面环境适配。
- 从 Finder 启动时的 Shell、PATH 和工作目录行为。

普通配置与敏感凭据分别保存。采集任务采用共享调度，避免页面重复采集；后台或不可见状态降低刷新频率。具体库、刷新周期和持久化格式在能力验证后确定。

## 6. 实施阶段与验收

| 阶段 | 工作 | 验收依据 |
| --- | --- | --- |
| 1. 底层能力验证 | 端口映射、进程指标与权限、交互式 PTY、SSH/SFTP | 在真实 Mac 和 Linux 服务器上记录可用能力、权限限制与待解决项 |
| 2. 应用骨架与端口闭环 | 导航、基础主题、端口列表、搜索、结束与刷新 | 找到真实监听端口，结束正确进程并确认释放；失败能正确反馈 |
| 3. 进程与本地终端 | 资源排序、详情、多会话、快捷指令 | 能比较真实进程占用，执行指令、查看输出并停止任务；会话切换正常 |
| 4. SSH 与文件管理 | 保存连接、认证、远程终端、SFTP | 能连接 Linux，浏览目录并完成真实上传下载、取消与失败反馈 |
| 5. 外观与桌面交付 | 自定义背景、持久化、打包与桌面运行 | 重启后配置保留；打包应用从 Finder 启动后各主要流程正常 |

阶段交付时明确区分已完成、部分完成和未验证。演示数据必须标注，不能作为真实系统能力的验收证据。

## 7. 优先验证的问题

- macOS 不同权限下，端口、命令行、进程路径和资源指标的可获取范围。
- 单进程网络速率的采集方案、开销与准确性。
- 进程磁盘统计是否满足预期口径，以及差分采样方式。
- CPU 百分比的多核口径，避免与系统工具比较时产生歧义。
- Finder 启动环境中的用户 Shell 与开发工具路径。
- 终端高吞吐输出时的响应性、内存上限与退出清理。
- SSH 认证、主机指纹、SFTP 兼容性和断线行为。
- macOS 最低支持版本、芯片架构和后续分发方式，在打包前明确。
