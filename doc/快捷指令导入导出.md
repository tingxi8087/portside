# 快捷指令导入导出

2026-10-15

终端和 SSH 共用指令库，也共用导入导出功能。

- 标题栏「更多」：导入快捷指令、导出全部、导出当前筛选结果。
- 多选工具栏：导出所选。空列表或没有选择时禁用相应导出入口。
- 桌面使用 macOS 原生文件选择及保存窗口；浏览器预览使用文件选择及下载。
- 导入先预览名称、命令、目录、标签，默认勾选可导入项，可取消部分或全部选择。
- 名称、命令、目录、标签完全相同则跳过，包括同一文件中的重复项。
- 同名但内容不同创建副本，自动分配无冲突的「副本」「副本 2」名称，不覆盖已有指令。
- 每条生成新 ID，原有标签复用，新标签自动加入；一次批量更新并持久化。
- 导入后清空搜索与标签筛选，退出多选，新指令置顶并滚动、聚焦第一条。
- 仅保存配置，不创建会话、不执行命令；路径保留，命令中的换行保留。

## 文件格式

UTF-8 JSON，只包含快捷指令配置，不包含服务器、凭据、会话或运行状态。

```json
{
  "format": "portside-shortcuts",
  "version": 1,
  "shortcuts": [
    {
      "name": "查看 Git 状态",
      "command": "git status",
      "directory": "~/project",
      "tag": "Git"
    }
  ]
}
```

未分类使用 `"tag": null`。拒绝错误格式、不支持的版本、无效条目与空文件；任意条目无效则整份文件不导入。单文件最大 4 MB、最多 1000 条，大批量可筛选或多选后分批导出。取消文件选择不改变数据。

## 验证

- `node --test scripts/shortcut-transfer.test.mjs`：7 个测试，覆盖多行命令和中文路径往返、字段隔离、文件校验、大小和数量边界、已有及文件内重复、连续名称冲突。
- 浏览器实际选文件：3 条输入中跳过 1 条重复、1 条同名变副本，勾选数量正常更新，确认后新增 2 条并合并标签、置顶聚焦。
- 导出全部、所选、标签筛选分别生成 5 / 1 / 2 条 JSON，检查实际文件字段与条数。
- SSH 面板可见同一批导入内容，未连接时仍能使用导出。
- 原生 App：从系统文件窗口读取临时 JSON、预览、导入 1 条，再从系统保存窗口导出；实际 JSON 校验通过。本机测试指令已删除，原有空指令库保持不变。
- TypeScript、Vite 和 Tauri App 构建通过。
