# 本地 SSH 凭据存储

更新日期：2026-10-15。用户已选择「本地明文保存，重启免输」，此方案取代原 macOS 钥匙串方案。

## 当前行为

- 服务器资料、快捷指令、标签和外观仍写入 `~/Library/Application Support/com.portside.desktop/workspace.json`。
- SSH 密码和私钥口令写入同目录独立的 `ssh-credentials.json`，以连接 UUID 索引，内容为明文；不复制私钥文件，只在服务器资料中记录其路径。
- 凭据文件权限 `0600`。写入采用独占临时文件、同步数据、原子替换；串行保护并发读写。格式无效、版本不支持或内容超过 8 MB 时拒绝覆盖。
- 新建连接默认勾选「保存凭据到本机（明文）」。编辑已保存连接时密码框不回显；留空使用保存的值。取消勾选并保存会删除该连接的落盘凭据，本次运行仍可保留内存中的已输入值。
- 删除连接同步删除本地凭据；其他连接不受影响。
- 应用源码及直接依赖已移除系统钥匙串调用。旧钥匙串条目不自动迁移、不访问、不删除；如此前保存过密码，需要重新输入并保存一次。
- 主机指纹验证、SSH Agent、私钥认证和 SFTP 保持原行为。主机首次信任提示仍会出现，与钥匙串无关。

文件结构：

```json
{
  "version": 1,
  "credentials": {
    "连接 UUID": { "password": "密码", "passphrase": null }
  }
}
```
