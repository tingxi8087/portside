# 静态界面与交互预览

日期：2026-10-15

目的：先验收界面方向、信息密度和操作路径，再接入真实系统能力。

## 本轮范围

- Tauri 2 + React 项目骨架、macOS 原生窗口和应用图标。
- 顶部四个 Tab：端口、进程、终端、SSH；设置通过右上角弹窗打开。
- 活动监视器式布局：无侧栏、无大标题、单行工具栏、31px 紧凑列表与按需详情。
- 列表即时筛选、排序、演示进程结束与详情跳转。
- 演示终端、多个标签、快捷指令配置和模拟运行。
- SSH 配置编辑、模拟连接、按需展开的远程文件面板。
- 基础模拟文件操作、上传进度和演示文本下载。
- 主题、背景图片、透明度、模糊、终端配色及本地配置保存。
- Cmd+K 快速操作和小窗口下的导航、列表适配。

## 演示边界

1. 所有端口、进程和资源占用均为固定假数据，不采集系统信息。
2. 结束进程只删除内存中的演示条目，刷新按钮恢复初始数据。
3. 暂停刷新仅预览按钮状态；本轮没有实时采集和指标更新。
4. 终端使用预设输出模拟交互，尚未接入 PTY 或 xterm.js。
5. SSH 不发起网络连接，不验证主机指纹，不进行真实认证。
6. 密码和密钥路径表单不持久化；实际钥匙串集成尚未实现。
7. 文件列表位于内存，模拟上传仅保存文件名等元数据，不上传或读取文件内容；下载生成明确标注的本地演示文本。
8. 目录和演示文件变更按服务器缓存在内存中，切换服务器与主页面保留；刷新或重启后重置。
9. 文件修改时间以预置数据展示在提示中，独立修改时间列、右键菜单、终端输出搜索与复制菜单等完整设计留待后续实现。
10. 本轮没有提权助手、后台监控、自动更新和正式签名公证发布。

## 建议验收路径

1. 端口页输入 3000，查看详情、模拟结束，确认搜索结果和工具栏数量变化；点击刷新恢复。
2. 进程页切换筛选，按 CPU 或内存排序，展开更多列与进程详情。
3. 终端页运行“启动前端”，停止演示任务；新增一条 pwd 快捷指令并保存运行，确认目录输出。
4. SSH 页新增或编辑连接，点击连接，展开文件面板，进入 apps 目录并新建目录。
5. 设置页切换明暗和终端配色，选择本地图片并调整透明度、模糊，刷新后确认外观仍保留。
6. 使用快速操作搜索并打开页面或执行已保存的快捷指令。

## 紧凑布局修订（2026-10-15）

根据用户首次界面验收反馈，将侧栏工作台改为顶部四 Tab 工具窗口。取消大标题、口号、资源概览、底部装饰与重复提示；端口与进程筛选改为下拉，快捷指令默认收起，设置改为弹窗。功能交互与演示边界保持不变。

已实际点通四 Tab 导航、终端快捷指令展开与运行，以及设置弹窗。旧截图保留作为上一版记录，最新截图见 [紧凑版端口页](screenshots/ports-compact.jpg)。

## 纸墨组件修订（2026-10-15）

统一使用 Paper Ink 的 Tabs、Button、Input、Select、Dropdown、Segmented、InputNumber、Slider 和 Progress。移除绿色强调与强调色设置，终端、状态和应用图标同步改为中性纸墨色板。已验证主题切换、滑块键盘调节、快捷指令菜单编辑、运行与停止，以及 SSH 认证方式选择。

## 终端与 SSH 固定右栏修订（2026-10-15）

终端快捷指令改为固定右栏；SSH 改为左侧远程会话、右侧连接 / 文件 Tab。文件面板跟随当前远程会话，并按服务器在内存中缓存目录和演示文件。移除原来的展开、收起和关闭面板入口。统一右栏宽度，支持空状态和独立滚动。

真实 PTY、SSH/SFTP 仍未接入；以上连接、执行与文件操作均为本地演示。
